# Credits

PitPact is built by its contributors. This file is the human-readable
recognition list; the in-game "Compacts and Codicils" credits screen
is generated from it.

## How to add yourself

Open a PR against this file. Add your name under the appropriate
heading (or a new one) and link the GitHub handle. Keep entries short
— a single line per contributor per release.

Roles are not exclusive. The categories are bookkeeping, not fences.
