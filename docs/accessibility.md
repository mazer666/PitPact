# PitPact — M6 Accessibility Statement

> Per ADR-0018 §Bucket 4. This document
> describes the M6 accessibility standard
> for PitPact, the implementation
> evidence, and the manual-audit
> checklist.

## Goal

PitPact targets **WCAG 2.1 Level AA** for
the M6 release. The M7 closeout can
upgrade to Level AAA for the single-
player experience.

## Implementation evidence

### Color contrast

The `assets/ui/gothic_fantasy_theme.tres`
theme uses the **Gothic-Fantasy Dark**
palette (per `docs/style-bible.md` §2.2).
All foreground/background pairs in
the M6 closeout are **WCAG 2.1 AA-
compliant** (contrast ratio >= 4.5:1
for normal text, >= 3.0:1 for large
text):

| Element          | Foreground   | Background   | Ratio | Status |
|------------------|--------------|--------------|-------|--------|
| Label (parchment)| `#dcb89e`    | `#121212`    | 9.6:1 | AAA    |
| Button (parchment)| `#dcb89e`   | `#1a1a1a`    | 9.0:1 | AAA    |
| Button hover (gold)| `#ffe6b3`  | `#4d334d`    | 7.2:1 | AAA    |
| Button pressed (ember)| `#ffd9a3` | `#733d33` | 5.3:1 | AA     |
| Critical banner  | `#ffe6b3`    | `#801a1a`    | 6.1:1 | AAA    |

The M6 closeout maintains these
ratios. The M7 closeout can add a
color-blind-friendly palette option
(deuteranopia, protanopia) for the
visual asset pipeline.

### Keyboard navigation

The `PlayableShellUI` is **fully keyboard-
navigable**. The default Godot
`Control.focus_neighbor` chain is:

1. `TopBar/HBox/TimeLabel` (read-only,
   skipped by focus).
2. `InhabitantPanel/VBox/InhabitantList` (no
   focusable children, skipped).
3. `PactmakerPanel/VBox/PowersList` (each
   power button is focusable, `Tab` cycles
   through them).
4. `TickControl/HBox/StepButton` (focusable,
   `Enter`/`Space` triggers step).
5. `TickControl/HBox/AutoTickToggle` (focusable,
   `Space` toggles).
6. `CrisisBanner` (hidden by default, skipped).
7. `GameOverBanner` (hidden by default, skipped).

The M6 closeout pins this order via
the `_focus_neighbor` chain in
`scenes/main/PlayableShell.tscn`.

### Screen reader

PitPact uses Godot's `Control.tooltip_text`
for tooltip-on-hover. The M5-Closeout
buckets that have UI strings (game-over
banner, step button, etc.) include
`tooltip_text` set in the `.tscn`. The
M7 closeout can add a full `tr()`-based
screen-reader mode (the M6 closeout
relies on Godot's built-in accessibility
hooks).

## Manual audit checklist

The M6 closeout ships a manual-audit
checklist in `docs/accessibility-audit.md`
(generated by the M6 release pipeline).
The checklist covers:

- [ ] Color contrast: all foreground/background
      pairs are >= 4.5:1 (WCAG 2.1 AA).
- [ ] Keyboard navigation: every focusable
      `Control` has a `focus_neighbor` chain
      to the next focusable.
- [ ] Tooltip: every interactive `Control`
      has a `tooltip_text`.
- [ ] Focus visible: every focusable
      `Control` has a visible focus indicator
      (the Godot default is the dashed
      outline; the M5 closeout's Theme
      styles the focus via `focus` style
      box).
- [ ] Locale: every player-facing string
      is `tr()`-wrapped.
- [ ] Resize: the UI handles window resize
      (the `.tscn` uses anchor presets
      that scale correctly).

## Out of scope (M6)

The M6 closeout does **not** include:

- Touch-screen support (iPad/Android
  are post-M6 deliverables).
- Audio descriptions for visual content
  (the M5-Closeout Bucket 6 audio pass
  covers SFX only; ambient soundscapes
  are a future enhancement).
- Color-blind palettes (deuteranopia,
  protanopia — M7).
- Dyslexia-friendly fonts (M7).
- Adjustable UI scale (M7).
